# 02 · 验证

> 记录"哪些路走通了、哪些被证伪"，以及每条结论对应的实车现象。
> 验证环境：长安启源 C589 PHEV，启源 OS（Android 9 / API 28），2026-08。

---

## 1. 验证目标

1. 确认车机上的"工程模式"是哪一个应用；
2. 确认"USB 切换"最终写到哪一层；
3. 找出第三方应用可用的 ADB 开启路径；
4. 明确哪些路径**不可行**，避免车友重复踩坑。

---

## 2. 失败路径（已证伪）

### 2.1 直接写 `sys.usb.config`

```bash
# 仅用于说明"为什么不行"，不要在生产环境尝试
setprop sys.usb.config mass_storage,adb
```

结果：被 SELinux 拒绝。普通应用和 adb shell 都不具备该系统属性的写权限。

### 2.2 借道 MTK EngineerMode 的 emsvr

- 反编译可见 `ShellExe.execCommandOnServer` 会向 LocalSocket 发送
  `FUNCTION_EM_SHELL_CMD_EXECUTION=80001`；
- 实车检查：本车**没有** `/dev/socket/EngineerModeServer`；
- 且该应用运行在 radio uid 域，普通应用无法连入。

结论：死路。

### 2.3 HIDL `IEmd.setUsbPort()`

- 属于 `vendor.mediatek.hardware.engineermode`；
- untrusted_app 没有 HIDL 访问权；
- 且它控制的是 UART/USB 端口切换，不是 ADB 开关本身。

结论：不可行。

### 2.4 无障碍自动化点击

尝试链路：

```
拉起 TSP Factory MainActivity
  → 输入 6 位 PIN
  → 进入"USB 切换"
  → 点击"切换为 ADB 模式"
```

结果：**失败**。切换前出现"安全开启工程模式"的车端认证（绑定手机号），
界面认证不通过就不执行切换。自动化只能过 PIN，过不了第二道门。

结论：UI 自动化不是可行路径。

### 2.5 `Settings.Global` 写法（部分有效、本场景无效）

```java
Settings.Global.putInt(cr, "adb_enabled", 1);
Settings.Global.putInt(cr, "usb_mass_storage_enabled", 1);
```

- 这是"开发者选项 → USB 调试"同款通道，机制本身成立；
- 但在本车的 TSP Factory USB 切换场景下，实测：
  - 写入成功（无异常）；
  - `sys.usb.config` 不变；
  - `adb devices` 不恢复；
  - PC 端不出现 U 盘。
- 原因：该链路由 MCU 属性控制，`Settings.Global` 的键在这条路径上没有监听者。

结论：对"开发者选项里的 ADB 开关"有效，对"USB 口 host/device 角色切换"无效。

## 3. 成功路径

### 3.1 条件

1. 应用能通过 CarService 入口校验（机制见 [01-原理.md](01-原理.md) 第 4 节）；
2. 能拿到 `mcu` CarManager；
3. 写入 `ID_MCU_USB_MODE_SELECT = 557921325`，值为 1（ADB）或 2（U 盘）。

### 3.2 实车现象

| 操作 | 现象 |
|---|---|
| 写值 2（U 盘模式） | PC 端出现 U 盘；`adb devices` 断开；车机提示 USB 连接方式变化 |
| 写值 1（ADB 模式） | U 盘消失；`adb devices` 恢复；可继续 adb 调试 |
| 重复切换 | 稳定，未见需要重启 |

### 3.3 结论

> USB 模式的切换可以通过 MCU 属性完成；界面上的 PIN 与二级认证只保护 UI，
> 不保护底层属性写入。

这同时验证了"入口校验依赖进程名"这一结论：一旦进入 CarService，
后续属性写入没有被额外拦截。

## 4. 验证结果汇总

| 路径 | 机制成立 | 本车可用 | 结论 |
|---|---|---|---|
| `sys.usb.config` | ✅ | ❌ | 权限不足 |
| emsvr LocalSocket | ❌ | ❌ | socket 不存在 |
| HIDL `IEmd` | ✅ | ❌ | 无访问权 |
| 无障碍自动化 | ✅ | ❌ | 二级认证拦截 |
| `Settings.Global.adb_enabled` | ✅ | ⚠️ | 只对开发者选项有效 |
| MCU 属性 `557921325` | ✅ | ✅ | 与 TSP Factory 同款 |
| 远程 ADB（T-Box 作业） | ✅ | ❌ | 车厂云端链路，app 侧不可用 |

## 5. 证据形式

本仓库不附带原始日志、截图和反编译产物，原因：

- 日志含设备标识、位置和账号信息；
- 反编译产物属于第三方版权内容；
- 部分截图能看到 VIN / 手机号。

结论以"现象 + 判定"的形式记录；如果你要复现，请在自己的车上用只读命令观察，
不要把原始日志上传到公开仓库。
