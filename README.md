# 长安启源车机 · 工程模式与 ADB / USB 模式切换

> 记录长安启源车机（C589 PHEV / 启源 OS / Android 9）上，如何**第一次**打开 ADB，
> 以及打开之后如何让一个自研 APK **直接切换** ADB / U 盘模式、不再走工程模式。
>
> **适用版本**：启源 OS（Android 9 / API 28），2026-08 实车验证。
> 其他年款、配置或 OTA 版本可能不同，请以你的车为准。

---

## 两条路线，按顺序来

```
┌─────────────────────────────────────────────────────────────┐
│ 路线一：首次开启（必须走工程模式）                            │
│                                                             │
│ 车机工程模式 → 二级认证 → 笔记本热点 + DNS/证书劫持           │
│   → 假认证服务器返回成功 → 车机自己切换 USB 模式 → ADB 打开    │
└─────────────────────────────────────────────────────────────┘
                              ↓  ADB 已打开
┌─────────────────────────────────────────────────────────────┐
│ 路线二：进阶（不再需要工程模式）                              │
│                                                             │
│ adb 安装自研 APK → APK 通过 CarService 写 MCU 属性 557921325 │
│   → 值 1 = ADB 模式 / 值 2 = U 盘模式 → 一键切换              │
└─────────────────────────────────────────────────────────────┘
```

**关键区别**：路线一解决的是"车机不让普通应用碰 USB 模式"；
路线二解决的是"ADB 已经开了，不想每次都去工程模式点一遍"。

---

## 路线一：首次开启

### 为什么必须走工程模式

车机的 USB 模式切换入口在长安自研的 **TSP Factory** 工程模式里，外面还有两道门：

1. **6 位 PIN**：界面门；
2. **二级认证**："安全开启工程模式"，绑定手机号，走云端校验。

第二道门只挡 UI 操作。要过它，有两条思路：

- 冒充认证服务端，让车机以为认证成功（本仓库采用）；
- 绕过 CarService 直接写属性（这需要先能进 CarService，见路线二）。

### 认证绕过为什么成立

反编译与抓包确认：

- 登录请求走 `POST https://spm.auto-pai.com/tlc/auth/v1/{sms,login,authQuery}`；
- 该 App 的 `X509TrustManager` 是空实现、`HostnameVerifier` 恒真，**信任任何证书**；
- 客户端只看响应体的 `code` 字段，`0000` 即视为成功。

于是只要让车机把 `spm.auto-pai.com` 解析到我们的笔记本，再用自签证书起一个
HTTPS 服务器，三个接口都返回 `{"code":"0000",...}`，车机就会认为认证通过。

```
车机 ──连热点──> 笔记本（192.168.137.1）
                    ├─ hosts / DNS：spm.auto-pai.com → 192.168.137.1
                    └─ HTTPS :443（自签证书，CN=spm.auto-pai.com）
                          /tlc/auth/v1/sms        → {"code":"0000"}
                          /tlc/auth/v1/login      → {"code":"0000"}
                          /tlc/auth/v1/authQuery  → {"code":"0000"}
```

### 操作顺序

1. 笔记本开热点，车机连上；
2. 运行示例服务器（见 [examples/](examples/)）；
3. 车机进入工程模式 → 输入任意手机号 + 验证码 → 登录；
4. 认证通过后，点"切换为 ADB 模式"；
5. `adb devices` 看到设备，路线一完成。

完整原理：[docs/01-首次开启-工程模式与认证.md](docs/01-首次开启-工程模式与认证.md)
可运行示例：[examples/fake_tlc_server.py](examples/fake_tlc_server.py)

## 路线二：进阶（APK 直接切换）

ADB 打开后：

1. 用 adb 安装自研 APK（安装方式取决于你车机的安装门策略）；
2. APK 通过 CarService 拿到 `mcu` 管理器；
3. 写 `ID_MCU_USB_MODE_SELECT = 557921325`：
   - `1` = ADB 模式；
   - `2` = U 盘模式；
4. 以后切换只需要在车机上点一下，不必再开热点、跑假服务器。

**前提**：APK 需要能通过 CarService 的入口校验（该校验依赖进程名，机制见
[docs/02-进阶-APK直接切换.md](docs/02-进阶-APK直接切换.md)）。
